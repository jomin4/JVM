# JVM

《JVM 파헤치기》를 읽으며 만든 학습용 시각화 자료입니다. 각 페이지는 ◀ ▶ 버튼이나 ← → 키로 단계를 넘겨 봅니다.

| 자료 | 책 위치 | 단계 |
|---|---|---|
| [런타임 데이터 영역](https://jomin4.github.io/JVM/jvm-viz/runtime-data-areas.html) | 그림 2-1 | 16 |
| [HotSpot 인터프리터 — new 바이트코드](https://jomin4.github.io/JVM/jvm-viz/hotspot-new.html) | 2.3 객체 생성 | 33 |
| [객체 생성과 메모리 레이아웃](https://jomin4.github.io/JVM/jvm-viz/object-layout.html) | 그림 2-4 | 17 |

노션에서는 `/embed` 블록에 위 주소를 붙여 넣으면 됩니다. 임베드 창 폭에 맞춰 전체 화면이 같은 비율로 축소됩니다.
